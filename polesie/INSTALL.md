# Инструкция по установке и запуску системы "Полесьеэлектромаш"

## 🚀 Быстрый старт

### 1. Подготовка XAMPP
1. Установите XAMPP (если не установлен): https://www.apachefriends.org/
2. Запустите панель управления XAMPP
3. Запустите модули **Apache** и **MySQL**

### 2. Установка проекта
1. Скопируйте папку `polesie` в директорию `C:\xampp\htdocs\`
2. Откройте браузер и перейдите по адресу: http://localhost/phpmyadmin

### 3. Создание базы данных
**ВАЖНО!** Если база данных уже существует - удалите её сначала!

#### Вариант А: Через phpMyAdmin (рекомендуется)
1. В phpMyAdmin выберите базу данных `polesie_production` (если есть)
2. Нажмите вкладку "Операции" → "Удалить базу данных" (DROP DATABASE)
3. Нажмите вкладку "Импорт"
4. Выберите файл: `C:\xampp\htdocs\polesie\sql\database.sql`
5. Нажмите кнопку "Вперед" для импорта

#### Вариант Б: Через SQL-команду
1. В phpMyAdmin перейдите на вкладку "SQL"
2. Вставьте следующий код:
```sql
DROP DATABASE IF EXISTS polesie_production;
```
3. Нажмите "Вперед"
4. Затем импортируйте файл `database.sql` как в Варианте А

### 4. Вход в систему
1. Откройте браузер
2. Перейдите по адресу: **http://localhost/polesie/login.php**
3. Войдите под учетной записью:
   - **Логин:** `admin`
   - **Пароль:** `admin123`

## 🔧 Решение проблем

### Ошибка: "Constant BASE_PATH already defined"
**Решение:** Обновите файлы проекта до последней версии. Проблема исправлена.

### Ошибка: "Failed to open stream: No such file or directory"
**Решение:** 
1. Проверьте, что папка `polesie` находится в `C:\xampp\htdocs\`
2. Убедитесь, что все папки существуют: `config`, `includes`, `modules`, `assets`, `sql`

### Не могу войти (Неверный логин или пароль)
**Решение:**
1. Проверьте, что база данных импортирована корректно
2. Выполните SQL-запрос в phpMyAdmin:
```sql
SELECT username, password_hash FROM users;
```
3. Убедитесь, что пароли хранятся в открытом виде (admin123)
4. Если пароли захешированы - переимпортируйте базу данных

### Ошибка подключения к базе данных
**Решение:**
1. Убедитесь, что MySQL запущен в XAMPP
2. Проверьте файл `config/config.php`:
   - Хост: `localhost`
   - База данных: `polesie_production`
   - Пользователь: `root`
   - Пароль: `` (пустой)

### Страница показывает белый экран
**Решение:**
1. Включите отображение ошибок в `config/config.php`:
```php
ini_set('display_errors', 1);
error_reporting(E_ALL);
```
2. Проверьте логи Apache: `C:\xampp\apache\logs\error.log`
