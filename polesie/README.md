# Система управления производством "Полесьеэлектромаш"

## Описание проекта

Программный модуль системы контроля и управления производством электротехнической продукции для ОАО "Полесьеэлектромаш" (Республика Беларусь).

## Возможности системы

### Основные модули:

1. **Панель управления (Dashboard)**
   - Статистика по заказам, производству и качеству
   - Последние заказы и активные задания
   - Быстрые действия

2. **Управление заказами**
   - Создание и редактирование заказов клиентов
   - Отслеживание статусов заказов
   - Управление позициями заказов
   - Фильтрация и поиск

3. **Производство**
   - Создание производственных заданий
   - Отслеживание выполнения операций
   - Технологические маршруты
   - Назначение исполнителей и рабочих мест

4. **Контроль качества (ОТК)**
   - Входной, операционный, приёмочный и выходной контроль
   - Регистрация дефектов
   - Сертификаты качества
   - Статистика по качеству

5. **Складской учёт**
   - Управление остатками
   - Движение товаров
   - Инвентаризация

6. **Сотрудники**
   - Учёт персонала
   - Роли и права доступа
   - Журнал действий

7. **Отчёты**
   - Производственные отчёты
   - Отчёты по качеству
   - Анализ эффективности

## Технологии

- **Backend:** PHP 7.4+
- **Frontend:** HTML5, CSS3, JavaScript, Bootstrap 5
- **База данных:** MySQL/MariaDB
- **Сервер:** XAMPP/Apache

## Установка

### Требования:
- XAMPP 7.4 или выше
- MySQL 5.7+ или MariaDB 10.3+
- PHP 7.4+

### Шаги установки:

1. **Установите XAMPP**
   - Скачайте с https://www.apachefriends.org/
   - Установите в директорию по умолчанию (C:\xampp)

2. **Разместите файлы проекта**
   - Скопируйте папку `polesie` в директорию `htdocs`
   - Путь: `C:\xampp\htdocs\polesie`

3. **Настройте базу данных**
   - Запустите XAMPP Control Panel
   - Запустите Apache и MySQL
   - Откройте phpMyAdmin: http://localhost/phpmyadmin
   - Создайте новую базу данных `db_polesie`
   - Импортируйте файл `sql/database.sql`

4. **Настройте подключение к БД**
   - Откройте файл `config/config.php`
   - При необходимости измените параметры подключения:
     ```php
     define('DB_HOST', 'localhost');
     define('DB_NAME', 'db_polesie');
     define('DB_USER', 'root');
     define('DB_PASS', '');
     ```

5. **Запустите систему**
   - Откройте браузер
   - Перейдите по адресу: http://localhost/polesie
   - Войдите под учётной записью:
     - Логин: `admin`
     - Пароль: `admin123`
